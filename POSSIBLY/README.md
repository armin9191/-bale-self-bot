# POSSIBLY

ربات مدیریت گروه + سرگرمی + بازی برای بله — فقط گروه `@possibly`

## دستورات گروه (بدون اسلش)

| دستور | کار |
|-------|-----|
| بن [آیدی] یا ریپلای+بن | بن |
| کیک [آیدی] یا ریپلای+کیک | کیک |
| آنبن [آیدی] | آنبن |
| اکو متن | اکو |
| نجوا متن (ریپلای) | نجوا |
| یاد بگیر t r | یادگیری |
| فراموش کن t | حذف |
| لیست یادگیری | لیست |
| آمار | آمار امروز |
| دوز | بازی دوز |
| مافیا | مافیا |
| جرعت حقیقت | جرأت/حقیقت |
| ریپلای گیف + گیف متن | کپشن روی گیف |

## پیوی ربات

- `راهنما` / `منو` / `start`
- `آمار من` / `پروفایل`
- `بکاپ` یا `/backup` (فقط Owner) → فایل SQL/dump

## Config

توکن و DATABASE_URL داخل `config.py` خوانده می‌شوند.

## اجرا

```bash
cd POSSIBLY
pip install -r requirements.txt
python main.py
```

## Railway

`Procfile`: `worker: python main.py`  
`runtime.txt`: `python-3.12`

فونت فارسی: `assets/fonts/Vazirmatn-Regular.ttf`
